Portfolio

Il mio portfolio personale, costruito da zero con Astro e Tailwind CSS in un'estetica dark-fantasy — distintiva, ma leggibile e professionale. È bilingue, con un selettore che porta alla stessa pagina nell'altra lingua; progetti e post del blog sono content collection tipizzate che si modificano da Pages CMS senza toccare git; e il deploy è una GitHub Action che compila il sito da un repository privato e pubblica su GitHub Pages soltanto il risultato.

La sfida che ho risolto

GitHub Pages su un account gratuito pubblica solo da repository pubblici, e io volevo tenere il sorgente privato. La soluzione è separare codice e sito: il codice vive in un repo privato e, a ogni push su main, una GitHub Action compila il sito e spinge soltanto la cartella dist nel repo pubblico xyvanb.github.io, con un token limitato a quel solo repository. Chi visita vede il sito; nessuno vede il sorgente.

Perché è nato

Un portfolio serve a mostrare i progetti, ma è anche un progetto a sé: è la prima cosa che si vede di me. Volevo un sito veloce, senza cookie né tracciamenti, e riconoscibile — un’estetica da videogioco, con la scheda del personaggio e le barre di esperienza, tenuta però professionale e leggibile. Sotto la superficie le scelte sono quelle che farei per un cliente: statico, accessibile, facile da aggiornare senza toccare il codice.

Com’è fatto

Il sito è generato con Astro in output completamente statico: ogni pagina è un file HTML e non c’è nessun framework lato client. Il poco JavaScript che gira nel browser è vanilla e scritto a mano: lo sfondo a particelle della home (che resta fermo se il sistema chiede animazioni ridotte), le transizioni fra la card di un progetto e la sua pagina, e la galleria di screenshot delle pagine progetto — che si costruisce a runtime dalle immagini consecutive del Markdown, con frecce, tastiera, swipe e lightbox. Senza JavaScript le immagini restano semplicemente impilate una sotto l’altra.

Lo stile è Tailwind CSS 4, con i token del design — colori e font — definiti in un unico blocco @theme. I font, Cinzel per i titoli e Inter per il testo, sono serviti dal sito stesso tramite Fontsource, senza richieste a Google. Perfino favicon, icone PWA e immagine Open Graph escono da uno script Node senza dipendenze: un piccolo encoder PNG/ICO scritto a mano, con un font bitmap 5×7, che ridisegna tutto con la palette del sito a ogni npm run gen:assets.

Bilingue

Il sito esiste in italiano e in inglese con il routing i18n di Astro: l’italiano vive alla radice, l’inglese sotto /en. La versione italiana e quella inglese di ogni progetto condividono lo stesso nome file, così il selettore di lingua deve solo aggiungere o togliere il prefisso e porta sempre alla pagina corrispondente. Ogni pagina dichiara le alternative hreflang, la canonical e i meta Open Graph, e la sitemap è generata con le varianti per lingua.

Contenuti e Pages CMS

Progetti e post del blog sono content collection con uno schema Zod validato alla build: un campo mancante o un URL malformato fermano la build invece di produrre una pagina rotta. La redazione passa da Pages CMS, un’app ospitata che si collega al repository tramite GitHub App e scrive direttamente i file Markdown: ogni salvataggio è un commit sul branch di lavoro, l’interfaccia si costruisce da un solo file YAML e non c’è nessun backend da mantenere. È lo stesso approccio di Teyvat Center.

Il deploy

GitHub Pages su un account gratuito pubblica solo da repository pubblici. Il sorgente però sta in un repo privato: a ogni push su main una GitHub Action installa le dipendenze con Node 22, compila il sito e spinge la sola cartella dist nel repo pubblico xyvanb.github.io, con un token a permessi minimi che può scrivere solo lì. Il lavoro quotidiano avviene su develop; pubblicare significa portare develop su main, e quel push è il deploy. Una regola di concorrenza impedisce a due deploy di accavallarsi.

Il deploy mi ha lasciato anche una lezione: il lockfile generato su Windows non includeva i binari opzionali per Linux, e in CI npm ci falliva mentre in locale tutto funzionava. Rigenerarlo da zero ha risolto.
