Erica Morelli's Portfolio

A portfolio site for Erica Morelli, a graphic, web and UI designer based in Parma. It starts from the open-source Astro Haze theme, redesigned around her work: twelve projects imported from Behance with copy, covers and galleries, an archive filterable by tag, built-in search and a light or dark theme. Erica updates projects and copy from Pages CMS, and every save goes live on GitHub Pages by itself.

Challenge I solved

The site had to belong to Erica, not to me: repository, CMS and publishing on her account, and everything editable without writing code. I transferred the repository to her GitHub profile while staying on as a collaborator, made the page copy editable from Pages CMS and not just the projects, and reused my own portfolio's deploy setup: the source stays private and a GitHub Action publishes only the built site to the public erica-93.github.io repo, with a token that can write there and nowhere else.

Why I built it

Erica is a graphic, web and UI designer, and her work was collected on Behance. With this site it has a home of its own, at an address that’s hers. The goal was a portfolio that lets the projects speak — big images, short copy — and that she could keep up to date on her own, without going through me for every new piece.

From theme to site

The base is Astro Haze, an open-source Astro theme with a frosted-glass look. I kept its structure and removed everything that wasn’t needed: the demo blog and landing page are gone, the home and “About” pages were rewritten around Erica’s three areas — brand identity, web design and interfaces — and the accent color became violet.

The content comes from Behance: twelve projects imported with title, description, role, year, tools, cover and gallery, plus a link to the full case study. Images go through Astro’s pipeline, which resizes them and converts them to AVIF and WebP. The archive can be filtered by tag, built-in search powered by Pagefind finds projects and copy without any external service, and the light or dark theme follows the system setting, with a button to switch it.

She edits, the site updates

Editing goes through Pages CMS, as on my own portfolio and on Teyvat Center: Erica signs in with her GitHub account and adds or edits projects from a form. Here the page copy is editable too — home, “About”, archive, site details — stored in JSON files that the Astro pages read directly. The CMS schema mirrors the content collections, and a short guide in the repository walks Erica through adding a new piece.

Every save is a commit on the main branch, and every commit triggers a GitHub Action that builds the site and pushes the dist folder to the public erica-93.github.io repository, served by GitHub Pages: a few minutes after Erica hits “Save”, the change is live.

Tech stack

The site is generated with Astro 7 as fully static output, with content collections typed in TypeScript and validated at build time, and very little client-side JavaScript: search, archive filters, theme switching and the mobile menu. Pagefind builds the search index after the build, the sitemap is generated automatically, and deployment is a GitHub Action that publishes to GitHub Pages through a separate repository.
